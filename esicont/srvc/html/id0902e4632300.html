SECURITY LIGHT: DTC 13 (WDS: DTC B1600)

id0902e4632300

DTC 13 (B1600)

ID number is not received.

POSSIBLE CAUSE

• No transponder in the key
• Defective transponder in the key (ID number is not output.)
• Defective coil
• Defective PCM

Diagnostic procedure

Step

Inspection

Action

1
VERIFY DTC USING SST
• Does WDS indicate DTC B1600?
Yes
Go to Step 3.
No
Go to the next step.
2
VERIFY DTC USING SST
• Does WDS indicate DTC B2431?
Yes
Go to SECURITY LIGHT: DTC 13 (WDS: B2431).
No
Go to the next step.
3
VERIFY VALID KEY
• Is there any key, other than the one that caused displayed DTC, which can start the engine?
Yes
Go to Step 5.
No
Go to the next step.
4
VERIFY WHETHER MALFUNCTION IS IN COIL OR KEY
• Using WDS register an additional key.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
• Using registered key, turn ignition switch to ON position.
• Does WDS indicate DTC B1600 again?
Yes
Replace coil, then go to step 6.
(See COIL REMOVAL/INSTALLATION.)
No
• Dispose of defective key.
• Duplicate key if necessary.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
5
VERIFY WHETHER MALFUNCTION IS IN COIL OR KEY
• Using any other valid key, turn the ignition switch to the ON position.
• Does WDS indicate DTC B1600 again?
Yes
Replace coil, then go to the next step.
(See COIL REMOVAL/INSTALLATION.)
No
• Dispose of defective key.
• Duplicate key if necessary.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
6
INSPECT PCM
• Using registered key, turn the ignition switch to the ON position.
• Does WDS indicate DTC B1600 again?
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
Troubleshooting is completed.
