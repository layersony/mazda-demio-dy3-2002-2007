ENGINE FEATURES [ZY]

id0100001002a0

Mechanical

Improved engine performance
• A variable valve timing mechanism has been adopted.
Reduced engine weight
• Main parts (cylinder head and cylinder block) are made of aluminum alloy.
Reduced engine noise and vibration
• The cylinder head is made of aluminum alloy.
• A silent timing chain has been adopted.
• A highly rigid aluminum cylinder block and lower cylinder block have been adopted.
• A crankshaft pulley with torsional damper has been adopted.
• A pendulum type engine mount has been adopted.
Improved serviceability
• A serpentine type drive belt has been adopted.
• Drive belt tension is adjusted automatically with an auto-tensioner.
• A timing chain has been adopted to eliminate the need for its replacement.
• An engine front cover with a service hole has been adopted. (for unlocking the chain adjust ratchet and securing the tensioner arm.)

Lubrication System

Reduced weight
• An aluminum alloy oil pump cover has been adopted.
• A plastic oil strainer has been adopted.
Improved lubrication and reliability
• A trochoid gear type oil pump has been adopted.
• An oil jet valve has been adopted.

Cooling System

Reduced weight and size
• A down-flow type radiator with radiator tanks made of plastic and a core made of aluminum has been adopted.
• A built-in type water pump has been adopted.
Reduce engine noise and vibration
• An electric cooling fan has been adopted.

Intake-Air System

Improved engine torque
• Variable intake air system adopted
Improved noise reduction
• Resonance chamber adopted
Improved emission gas purification
• Variable tumble system adopted

Fuel System

Improved serviceability
• Nylon tubes adopted for fuel hoses in the engine compartment and around the fuel tank, and quick release connectors adopted for joints
Reduction of evaporative gas
• Returnless fuel system adopted

Emission System

Improved exhaust gas purification
Exhaust gas recirculation (EGR) system adopted
Catalytic converter system adopted
Water-cooling type EGR cooler adopted

Control System

Improved driveability
• Drive-by-wire control adopted
• Variable intake air control adopted
• Variable valve timing control adopted
Improved exhaust emission performance
• Variable tumble control adopted
• Wide-range air/fuel ratio sensor has been adopted for the front HO2S sensor
• EGR control adopted
Improved fuel economy
• Variable tumble shutter valve switch adopted
• Current sensor adopted
Wiring harness simplification
• CAN adopted

Charging System

Reduced size and system simplification
• A regulatorless generator with built-in power transistor has been adopted.

Ignition System

Improved marketability and durability
• Direct ignition system have been adopted.

Starting System

Improved safety
• A reduction type starter has been adopted.
