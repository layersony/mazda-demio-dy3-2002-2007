• When the customer reports a vehicle malfunction, inspect the malfunction indicator lamp (MIL), HOLD indicator light*1, AT warning light *2 indication, and PCM memory for diagnostic trouble code (DTC), then diagnose the malfunction according to the following flowchart.
- If a DTC exists, diagnose the applicable DTC. (See DTC TABLE [FN4A-EL].)
- If no DTC exists, the MIL does not illuminate, and AT warning light does not illuminate. Diagnose the applicable symptom troubleshooting. (See SYMPTOM TROUBLESHOOTING ITEM TABLE [FN4A-EL].)
