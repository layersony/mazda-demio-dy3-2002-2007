LIGHTING SYSTEMS OUTLINE

id091800100100

Design Improvement
• Front combination lights with built-in headlight, front turn light, and parking light have been adopted.
• Front fog lights have been adopted. (Located in front bumper)
Improved visibility
• Discharge headlights wide-area illumination have been adopted on the quadruple headlights. (low-beam)
• Interior light control system that changes illumination time and intensity has been adopted.
Improved convenience
• Headlight auto leveling system that constantly maintains the headlight (low-beam) beam angle has been adopted.
Improved marketability
• Headlight leveling system providing a freely adjustable headlight (low-beam) beam angle has been adopted.
• LEDs have been adopted for the high-mount brake light.
• Panel light control switch providing freely adjustable illumination level has been adopted.
