ENGINE COOLANT LEVEL INSPECTION [ZY]

id0112008003a5

1. Remove the radiator cap and verify that the engine coolant is filled close to the top.

2. Verify that the engine coolant level in the engine coolant reservoir is between the F and L marks.

Note
• If the "FL22" mark is shown on or near the cooling system cap, use FL22 type engine coolant.
• FL22 type engine coolant is shipped as a diluted solution (55% coolant, 45% water). Use the solution as is when replacing coolant.

3. If the engine coolant level is below L, add the engine coolant.
