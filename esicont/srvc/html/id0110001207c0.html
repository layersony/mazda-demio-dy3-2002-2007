VARIABLE VALVE TIMING MECHANISM CONSTRUCTION [ZY]

id0110001207c0

• The variable valve timing mechanism consists of a variable valve timing actuator, oil control valve (OCV), CKP sensor, CMP sensor, and the PCM.

Hydraulic Pressure Flow Diagram

Component and function

Variable valve timing actuator
• Continuously modifies the phases of the intake camshaft and crankshaft at the forward end of the intake camshaft using hydraulic pressure from the oil control valve (OCV).
Oil control valve (OCV)
• Operated by current (duty signal) from the PCM. Controls the hydraulic oil passages to the variable valve timing actuator.
CKP sensor
• Inputs engine revolution signal to the PCM.
CMP sensor
• Inputs cylinder identification signal to the PCM.
PCM
• Controls the oil control valve (OCV) so that optimum valve timing is obtained according to engine operation conditions.
