DTC P0108

MAP sensor circuit high input

DETECTION CONDITION

• The PCM monitors the input voltage from the MAP sensor. If the input voltage is more than 4.8 V, the PCM determines that the MAP sensor circuit has a malfunction.
Diagnostic support note
• This is a continuous monitor (CCM).
• The MIL illuminates if the PCM detects the above malfunction condition in the first drive cycle.
• The PENDING CODE is available if the PCM detects the above malfunction condition.
• The FREEZE FRAME DATA is available.
• The DTC is stored in the PCM memory.

POSSIBLE CAUSE

• MAP sensor malfunction
• Connector or terminal malfunction
• Open circuit in the wiring harness between MAP sensor terminal B and PCM terminal 2AP
• Short to power supply in the wiring harness between MAP sensor terminal B and PCM terminal 2AP
• Open circuit in the wiring harness between MAP sensor terminal A and PCM terminal 2J
• PCM malfunction
