4

Sound jumps

Possible DTC:03:Er02, 06:Er02, 10:Er02, 22:Er02

Troubleshooting hints
• Audio unit is malfunctioning
• Defective CD (e.g., cracked, badly bent, rough edges, scratch, dirty CD, condensation)
• Improper audio unit installation (e.g., rattle, loose)
• Inadequate tire pressure
Note
• The CD may be malfunctioning if the sound jumps on the certain CD only. Inspect the CD player/changer operation using a CD known to be operational.
