POWER WINDOW MAIN SWITCH INSPECTION

id091200419000

Driver's side

1. Remove the front door trim. (RH)

2. Connect the power window main switch connector.

3. Measure the voltage at the each terminal as indicated below (other than terminals 1M and 1O).

4. Disconnect the power window main switch connector before inspecting for continuity at terminals 1M and 1O.

• If not as specified, inspect the parts listed under "Inspection item (s)".
• If the parts and wiring harnesses are normal but the system still does not work properly, replace the power window main switch.

Except driver's side

1. Turn the power-cut switch to UNLOCK.

2. Inspect for continuity between the power window main switch terminals.

• If not as specified, replace the power window main switch.
