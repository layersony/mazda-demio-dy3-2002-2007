SUPPLIER IDENTIFICATION PROCEDURE

id0902f6358400

Note
•  The supplier can vary with the module. When asking the supplier (service center) for repair or replacement, fill in the Audio Repair Order Form by identifying the manufacturer with the following procedures.

Identification With the Label

1.  Remove the audio unit. (See CENTER PANEL MODULE DISASSEMBLY/ASSEMBLY.)

2.  Verify the supplier indicated on the label attached on the module.


Identification With the On-board Diagnostic procedure.

1.  Start the on-board diagnostic test mode.

2.  Verify the device code and supplier code displayed on the screen.
