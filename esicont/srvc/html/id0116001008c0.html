EVAPORATIVE EMISSION (EVAP) CONTROL SYSTEM OUTLINE [ZY]

id0116001008c0

• With the adoption of the charcoal canister, release of evaporative gas into the atmosphere has been prevented.
• A duty solenoid valve (purge control valve) has been adopted for optimum control according to engine operation conditions.
• For control of evaporative purge, refer to CONTROL SYSTEM, EVAPORATIVE PURGE CONTROL. (See EVAPORATIVE PURGE CONTROL OUTLINE [ZY], EVAPORATIVE PURGE CONTROL BLOCK DIAGRAM [ZY], EVAPORATIVE PURGE CONTROL OPERATION [ZY].)
