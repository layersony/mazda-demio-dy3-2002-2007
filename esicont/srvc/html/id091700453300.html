SHOCK ABSORBING PAD REMOVAL/INSTALLATION

id091700453300

FRONT

1. Remove the headliner. (See HEADLINER REMOVAL/INSTALLATION.)

2. Pull the rear part of the shock absorbing pad outward, then disengage clips A and pin B.

3. Disengage tab C, then remove the shock absorbing pad.

4. Install in the reverse order of removal.

REAR

1. Remove the headliner. (See HEADLINER REMOVAL/INSTALLATION.)

2. Pull the front part of the shock absorbing pad outward, then disengage clips A and pin B.

3. Disengage tab C, then remove the shock absorbing pad.

4. Install in the reverse order of removal.
