SECURITY LIGHT: DTC 21 (WDS: DTC B1213)

id0902e4632700

DTC 21 (B1213)

Number of valid keys is below minimum.

POSSIBLE CAUSE

• Less than two valid keys

Diagnostic procedure

Step

Inspection

Action

1
VERIFY NUMBER OF VALID KEYS
• Check the following PID/DATA monitor with WDS:
- NUMKEYS
• Does NUMKEYS display more than 2?
Note
• To start the engine, two or more keys need to be registered.
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
• Erase key ID numbers and register necessary key ID numbers.
• Go to the next step.
2
VERIFY DTC
• Does security light or WDS indicate DTC 21 (B1213) again?
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
Troubleshooting is completed.
