DTC P0537

Evaporator temperature sensor circuit low input

DETECTION CONDITION

• The PCM monitors the input voltage from the evaporator temperature sensor. If the input voltage is less than 0.08 V, the PCM determines that the evaporator temperature sensor circuit has a malfunction.
Diagnostic support note
• This is continuous monitor (CCM).
• The MIL does not illuminate.
• The PENDING CODE is available if the PCM detects the above malfunction condition.
• The FREEZE FRAME DATA is available.
• The DTC is stored in the PCM memory.

POSSIBLE CAUSE

• Evaporator temperature sensor malfunction
• Connector or terminal malfunction
• Short in to ground circuit between evaporator temperature sensor terminal B and PCM terminal 1AW
• PCM malfunction
