SPARK PLUG REMOVAL/INSTALLATION [ZY]

id0118008004b5

1. Disconnect the negative battery cable.

2. Remove the ignition coil. (See IGNITION COIL REMOVAL/INSTALLATION [ZY].)

3. Remove the spark plugs using a plug-wrench.

4. Install in the reverse order of removal.

Tightening torque
14.7-22.6 N·m {1.50-2.30 kgf·m, 10.9-16.6 ft·lbf}
