Clutch Pipe Removal/Installation

Caution
• Be careful not to spill clutch fluid on a painted surface. If this should happen, wash it off immediately.
Note
• A common reservoir is used for the clutch and brake system fluid.

1. If clutch pipes have been disconnected any time during the procedure, add clutch fluid (brake fluid), bleed the air, and inspect for leakage after the procedure has been completed.

2. Remove the clutch pipe using the SST (49 0259 770B). Install the clutch pipe using torque wrench SST combination. (See Torque Formulas.)
