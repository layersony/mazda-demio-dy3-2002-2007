DTC 15 (B1601)

PCM received incorrect ID number from key (transponder).

POSSIBLE CAUSE

• No keys have been registered after installation of new PCM
• Unregistered key detected
• Attempt made to register a ninth key
Note
• A maximum of only eight keys can be registered for a single vehicle.
• Defective PCM

Diagnostic procedure

Step

Inspection

Action

1
VERIFY REGISTERED KEY IN PCM
• Check the following PID/DATA monitor using WDS:
- NUMKEYS
• Does NUMKEYS display more than 0?
Yes
Go to the next step.
No
Go to Step 3.
2
VERIFY REGISTERED KEY IN PCM
• Check the following PID/DATA monitor using WDS:
- NUMKEYS
• Does NUMKEYS display more than 8?
Yes
• Erase key ID number using WDS and register key ID number.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
• Go to the next step.
No
Go to the next step.
3
INSPECT PCM
• Erase key ID number using WDS and register key ID number.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
• Using registered key, turn the ignition switch to the ON position.
• Does security light or WDS indicate DTC 15 (B1601) again?
Yes
Replace PCM and reprogram immobilizer system.
(See IMMOBILIZER SYSTEM COMPONENT REPLACEMENT/KEY ADDITION AND CLEARING.)
No
Troubleshooting is completed.
