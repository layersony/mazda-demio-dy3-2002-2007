CONSOLE REMOVAL/INSTALLATION

id091700801200

1. Insert a tape-wrapped flathead screwdriver into notches A on the cover, then disengage tabs B.

2. Disengage tabs C while lifting up the cover in the direction of the arrow.

3. Remove the screws and fasteners.

4. For MTX vehicles, slightly pull the console rearward, and disengage the tabs from the dashboard.

5. Install in the reverse order of removal.
