Speedometer

Using the input/output check mode

1. Inspect the speedometer by setting it to the input/output check mode check code 12. (See INSTRUMENT CLUSTER INPUT/OUTPUT CHECK MODE.)

Using a speedometer tester

1. Adjust the tire air pressure to the specification.

2. Using a speedometer tester, verify that the speedometer indication is within the allowable ranges shown below.

3. Verify that fluctuation of the speedometer needle is within the allowable range.

• If the speedometer needle does not move or fluctuation of the speedometer needle is not within the allowable range, inspect the PCM, ABS HU/CM (Vehicles with ABS) and the related wiring harnesses.
- If the PCM, ABS HU/CM (Vehicles with ABS) and related harnesses do not have any malfunction, replace the instrument cluster.

Tachometer

Using the input/output check mode

1. Inspect the tachometer by setting it to the input/output check mode check code 13. (See INSTRUMENT CLUSTER INPUT/OUTPUT CHECK MODE.)

Using the WDS or equivalent

Caution
• If the engine speed exceeds the allowable range, the engine could be damaged. Therefore, when inspecting the tachometer, do not allow the engine speed to exceed the allowable range indication on the tachometer.

1. Connect the WDS or equivalent to the vehicle DLC-2 16-pin connector.

2. Access and monitor PIDs using the WDS or equivalent.

Fuel Gauge

1. Inspect the fuel gauge by setting it to the input/output check mode check code 23. (See INSTRUMENT CLUSTER INPUT/OUTPUT CHECK MODE.)

Water Temperature Gauge

1. Inspect the water temperature gauge by setting it to the input/output check mode check code 25. (See INSTRUMENT CLUSTER INPUT/OUTPUT CHECK MODE.)
