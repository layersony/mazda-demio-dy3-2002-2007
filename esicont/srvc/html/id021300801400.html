Shock Absorber And Coil Spring Removal Note

1.  Separate the shock absorber and steering knuckle by tapping the steering knuckle.


Piston Rod Nut Removal Note

Warning
•  Removing the piston rod nut is dangerous. The shock absorber and spring could fly off under tremendous pressure and cause serious injury or death. Secure the shock absorber in the SSTs before removing the piston rod nut.

1.  Protect the coil spring using a piece of cloth, then set the SSTs.

2.  Compress the coil spring using the SSTs, and remove the piston rod nut.

Coil Spring Installation Note

1.  Compress the coil spring using the SSTs.

2.  Install the shock absorber so that the lower end of the coil spring is seated on the step of the lower spring seat.

3.  Install the bound stopper, dust boot, bearing, mounting rubber and piston rod nut, then remove the SSTs.

Piston rod nut tightening torque
55—67 N·m {5.7—6.8 kgf·m, 41—49 ft·lbf}


Bolt (Shock Absorber Lower Side) Installation Note

1.  Align the projection of the shock absorber with the notch of the steering knuckle.

2.  Push the lower arm using the jack.
