MAIN RELAY CONTROL OPERATION [ZY]

id0140001120c0

• When the ignition switch is turned to the ON position, the main relay turns on and power is supplied to sensors and devices.
• When the ignition switch is turned from on to off, a main relay on command signal is received the main relay turns on and the following actions take place:
1. Throttle valve control: Fully closed throttle learning function (See DRIVE-BY-WIRE CONTROL OPERATION [ZY].)
• When the on request signal from the controls stop, the main relay turns off.
