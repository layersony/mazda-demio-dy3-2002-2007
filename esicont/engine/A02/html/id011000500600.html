Knock Sensor Disassembly Note

1.  Remove the knock sensor using the SST.

bezeze00000015


Drive Plate (ATX), Flywheel (MTX) Disassembly Note

1.  Lock the drive plate (ATX) or flywheel (MTX) against rotation using the SST.

bezeze00000016

2.  Remove the drive plate or flywheel installation bolts.


Oil Filter Disassembly Note

1.  Remove the oil filter using the SST.

Oil Filter Joint Disassembly Note

1.  Remove the oil filter joint using the following procedure:

(1)  Install two appropriate nuts (M20 x 1.5) to the oil filter joint.
am2llw00000039
(2)  Using a wrench, apply force in the direction of the arrow shown in the figure and lock the nuts.
am2llw00000040
(3)  Using a wrench, apply force in the loosening direction for the inside nuts and remove the oil filter joint.
